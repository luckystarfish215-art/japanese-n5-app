# N5ingo

Duolingo-style Japanese N5 learning app.

## Features

- Listen to Japanese sentence
- Rebuild sentence from word cards
- Slow audio playback
- Speaking practice using browser speech recognition
- Traditional Chinese explanation
- Romaji support
- Mobile-friendly design

## Run locally

```bash
npm install
npm run dev
```

Open:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

## Deploy to Cloudflare Pages

Build command:

```bash
npm run build
```

Build output directory:

```bash
dist
```

Note: Speech recognition works best on Chrome-based browsers.
